# Minimum OS targets for SwiftUI App repositories

The following projects are tagged **SwiftUI App** in the repository gallery. Minimum versions are taken from each project's README unless an Xcode deployment target is noted.

| Repository | Minimum macOS version |

| [AgendaT](https://github.com/perez987/AgendaT) | macOS 13.0+ |
| [AgendaT-iOS](https://github.com/perez987/AgendaT-iOS) | No macOS target (iOS/iPadOS 16.0+) |
| [Audiometry](https://github.com/perez987/Audiometry) | macOS 14.6+ |
| [Audiometry-iOS](https://github.com/perez987/Audiometry-iOS) | No macOS target (iOS/iPadOS 18+) |
| [DownloadFullInstaller](https://github.com/perez987/DownloadFullInstaller) | macOS 13.0+ |
| [Easy-Ethernet-Icon](https://github.com/perez987/Easy-Ethernet-Icon) | macOS 13.5+ |
| [MacOS-Calculator](https://github.com/perez987/MacOS-Calculator) | macOS 15.1 (Xcode deployment target; not stated in README) |
| [MP3GainOSX-swiftui](https://github.com/perez987/MP3GainOSX-swiftui) | macOS 13+ |
| [MP3Player](https://github.com/perez987/MP3Player) | macOS 13.0+ |

For About-This-Hack, MacOS-Calculator, and XSL-Transform, the Xcode project deployment setting is recorded where it differs from or is absent from the README.
